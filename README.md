# Tool Loan Receipt

Record equipment condition and a return plan for a personal loan.

## Run

Run `python app.py` with Python 3.10+ and Tkinter. Edit the example in the **Edit** tab and check **Preview**. Save a JSON draft to continue later, or export the completed document as UTF-8 text. Open the text file in your preferred editor to print.

## Example

Change **Lender and borrower** from “Enter both names.” to your own details, then save and reopen the draft. Empty sections are omitted from the exported text.

## Limitations

Drafts are specific to this document type. Save before closing the window.
